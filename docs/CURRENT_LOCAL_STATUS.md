## 主要限制

- 没有恢复当前成品完整原始 Studio 播报 XML；旧 `.fspro` 是辅助编码/参考工程。当前可编辑实现是 bank 结构图、受限变更脚本、输入和验证合同。
- 原有条件在活动区间内跨档可能补触发；沿用旧规则，未加入统一防抖。66 秒移动测试保留全部原调用时刻并在新阈值跨越时多四次条件补触发。
- 原始事件 HASH 标签的完整语义未解码。主混音两条更改的 HASH 来自原生编译，新 WAV HASH 来自原生音频构建，其他原标签保留；通过所述真实运行库验证，不当作格式全解码。
- GitHub 纯文本仓库不包含声音或 bank 输入，没有这些输入无法仅凭文本产生同音色完整成品。
