## 不要重蹈的坑

- WAV索引是offset18的uint32，不是offset20的uint16。
- FMOD版本0x00020214表示2.02.14，不能把十六进制14转换成“2.02.20”名称。
- 需要父实例回调才能观察嵌套声；两个空回调列表不算节奏相同。
- WAVWRITER启动静默长度可差一个DSP块，旧音频比较按已观测DSP起播时钟对齐。
- 条件两端包含；新边界要处理float32端点，旧跨档补触发规则不能静默改掉。
- Studio编译辅助项目会输出新strings，不随意替换生产strings。
- 运行库搜索目录句柄要关闭，大批量渲染否则会耗尽Windows目录列表。
- 收集资料时不移动Steam/游戏、Python共用安装、Codex缓存和其他项目。
- 旧参考工程Scripts目录可包含启动即遍历/改写事件的脚本。bootstrap已排除它；不要恢复自动执行，编码只运行公开compile_voice_bank.js。

## GitHub 与本机的关系

根目录保存完整制作资料，`public-repo/` 是纯文本发布快照。GitHub不含私人/第三方二进制输入。其他机器需按REPRODUCE准备基线、录音、工具和参考工程；本机新Agent可以直接使用已集中资料。

发布收据记录目标仓库、父提交、提交和分支回读。工作开始时若远端已有新提交，不强制覆盖，先检查差异。旧公开README作为历史保留，新入口以真实已验收状态为准。
