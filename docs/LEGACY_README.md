# 战争雷霆语音包
首款开放下载的战争雷霆听觉增强语音包，全方位加强感知能力，支持自动语音报警。
关于语音包
欢迎使用战争雷霆语音包，一款为 War Thunder 地面战斗打造的听觉辅助语音模组。让自如分辨嘈杂交火中的发动机线索，不再是高手的专利。

这款语音包 能大幅降低友军与玩家自身载具的发动机、履带和悬挂噪音，让敌军踪影无处可匿。敌军发动机音量被显著增强，并且其随距离的衰减的曲线得到了细致优化。现在，你可以在200米的距离内听清敌军声音，并且并不影响距离的判断。

在最新版本 1.2.1 中，语音提示的更新为大家带来全新游戏体验。现在，每一个出现的发动机噪音实例，都会有清晰明确的中文语音提示播放，明确指出发动机类别和距离玩家的距离。(不同车辆可能使用相同的发动机音效，故发动机的播报语音不代表实际车辆,详细参考技术报告)

需注意当前发布为测试版，用于学习交流。距离报数等暂时做一定限制，防止滥用。如遇到声音过小，请尝试降低枪炮等其他音效，拉高音量。
